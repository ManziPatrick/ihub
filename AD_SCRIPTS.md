# 🎬 Bootskills Platform — Ad Video Creator Course

> **Course Overview:** 50 ad scripts organized into 6 modules + 1 quick-hit module.  
> **Total Duration:** ~25-30 minutes of speaking content.  
> **Format:** Each lesson = one standalone ad script with full dialogue, visual cues, and production notes.  
> **Audience:** On-camera spokesperson recording promotional videos for every platform feature.

---

## 📋 How to Use This Course

| Element | What To Do |
|---------|------------|
| **Modules** | Film one module per recording session. Each module covers one user role. |
| **Lessons** | Each lesson is a standalone video. Film them in order within a module. |
| **Duration** | Full scripts (30-60s) for deep dives. Short clips (15s) for social media. |
| **Visuals** | Each script tells you what to show on screen. Record your screen alongside your face. |
| **Key Terms** | These appear as text overlays during editing. |

**Suggested Recording Order:**
1. Module 7 (Quick Hits — warm up with the shortest scripts)
2. Module 1 (Platform Overview — set the stage)
3. Module 2 (Student Portal — biggest audience)
4. Module 3 (Trainer Portal)
5. Module 4 (Admin Portal)
6. Module 5 (Super Admin Portal)
7. Module 6 (Client Portal)

## 🎬 Production Quick Reference

### Delivery Style
- **Tone:** Warm, enthusiastic, knowledgeable — like showing a friend something cool
- **Pacing:** Conversational, not rushed. Leave brief pauses between points
- **Eye contact:** Speak directly to camera lens (that's your audience)
- **Gestures:** Point at on-screen elements as you mention them

### Visual Production
- **Screen recording:** Show the actual platform interface behind/alongside you
- **Cursor ring:** Use a visible cursor highlight/glow to show clicks
- **Zoom:** Zoom into specific elements when mentioning them
- **Text overlays:** Key terms (like "XP", "Streak", "Offline Mode") appear as text on screen
- **Background:** The platform itself is the best background
